# Повторный подсчёт с морфологией

Проверка выполнена 2026-10-09 на неизменённом `Quran_text.txt` (SHA-256 `295faa755008d0a292d2e285368a06dc478bf37cb5f29ed29bb06d7c6ca0bf0a`). Основной профиль и его 14 868 строк сохранены. Дополнительно использована версия 0.4 [Quranic Arabic Corpus](https://corpus.quran.com/download/) (QAC; © 2011 Kais Dukes, GNU GPL с условиями атрибуции). Её исходный файл скопирован без изменений в `sources/quranic-corpus-morphology-0.4.txt`; SHA-256 `a1d12923815341face765083805d2148ed2d9f5cc3f7d6665219d887675d8c46`.

QAC размечает 77 429 орфографических слов и 128 011 сегментов. В предоставленном тексте 77 800 токенов: 371 дополнительных границ возникает прежде всего из разделённого пробелом обращения `يَا أَيُّهَا` и подобных сочетаний. Шесть особых слияний перечислены в `qac_morphology.py`. По числу слов выровнены все 6 236 аятов; результат и ссылки на конкретные вхождения находятся в `data/qac_alignment.csv` и `data/morphology_audit.json`. Выравнивание основано на позиции в аяте с проверенными правилами слияния; арабское написание всех сегментов QAC не сравнивалось машинным переводом из Buckwalter. Поэтому таблицы QAC остаются отдельным профилем, а не изменяют основной подсчёт.

По всей основной таблице подготовлена `data/word_morphology_summary.csv`: для каждого из 14 868 ключей показаны все POS и леммы из однозначно выровненных вхождений, а случаи слияния отмечены отдельно. На её основе закончена проверка 405 исключительно служебных форм; омоним `من`, 11 написаний имени Бога и все 30 словоформ лемм дня и месяца разобраны отдельно. Это не заменяет исследование остальных содержательных слов. Актуальное число незавершённых строк выводится из `PROJECT_STATE.md`.

| Определение «дня» | Число | Причина различия |
| --- | ---: | --- |
| Ровно словоформа `يوم` без огласовок и приставок | 217 | Строка основной таблицы |
| Лемма `يوم` по QAC, все числа и приставки | 405 | Включает 375 единственных, 26 мужских множественных, 1 женское множественное и 3 двойственных формы |
| Лемма `يوم`, единственное число | 375 | Включает `يومكم` и `يومهم` — 10 грамматически единственных форм с притяжательным суффиксом |
| Те же единственные формы без `يومكم` и `يومهم` | 365 | Число появляется только после этого исключения; филологического основания исключать именно эти 10 форм не установлено |
| Отдельная лемма `يومئذ` | 70 | Значение «в тот день», у QAC отдельный ключ |
| Обе леммы, все числа | 475 | 405 + 70 |

**Число 356** среди этих последовательно заданных профилей не воспроизведено. Для его проверки нужны точные правила включения форм или список вхождений. Ни 356, ни 365 нельзя приписывать одной словоформе `يوم` (217). 365 суток в календарном году также не равно точной длине земного года: NASA указывает около 365,25 суток.

| Определение «месяца» | Число |
| --- | ---: |
| Ровно словоформа `شهر` | 4 |
| Лемма `شهر` по QAC, все числа | 21 |
| Лемма `شهر`, единственное число | 12 |
| Множественное число | 7 |
| Двойственное число | 2 |

Двенадцать форм единственного числа содержательно сопоставимы с 12 месяцами исламского календаря. Это **условное календарное соответствие**: год делится на 12 месяцев по принятой системе; число 21 получается при включении всех грамматических чисел. В самом Коране 9:36 число месяцев прямо задано как 12, поэтому совпадение частоты не свидетельствует об открытии внешнего природного закона.

Для леммы `قمر` QAC даёт 27 вхождений (`والقمر` 20, `القمر` 5, `وقمرا` 1, `للقمر` 1). [NASA](https://science.nasa.gov/moon/facts/) округляет время оборота Луны вокруг Земли до 27 земных суток; [Britannica](https://www.britannica.com/science/sidereal-month) даёт 27,321661 суток для сидерического месяца. Разница с 27 составляет 0,321661 суток, или примерно 1,18 %. Это **приблизительное числовое совпадение**. Синодический месяц имеет иную длительность; выбор сидерического периода и округления влияет на результат. Сравнение выбрано после просмотра частоты, поэтому статистическая необычность не установлена. **Новым это соответствие не является:** [Quran Miracles](https://www.quranmiracles.com/2011/03/the-moon/) публиковал ту же пару 27 и 27 суток 22 марта 2011 года. Прежние утверждения этого сайта о «чуде» не принимаются как доказательство закономерности.

Факты и выписки из внешних источников сохранены в `sources/evidence.json`. Перепроверка: `python quran_words.py verify && python qac_morphology.py`.
